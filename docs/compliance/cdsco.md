# CDSCO Compliance (Stub)

Clinical trial and pharmacovigilance alignment for India CDSCO-facing Life Sciences pack workflows.

- **Trial Coordinator** agent — eligibility and recruitment tracking
- **Safety Monitor** agent — AE/SAE triage with approval gates
- **Protocol Compliance** agent — GCP / protocol deviation checks
- **Regulatory Documentation** agent — CDSCO-oriented report drafts
- Workflows: Patient Recruitment, Safety Reporting, Trial Closeout
- Immutable audit export for inspection readiness
