# India Compliance (Stub)

EIOS targets India-first enterprise customers with INR pricing and Razorpay integration. This document is a stub for regulatory alignment.

## Frameworks

- **DPDP Act 2023:** Consent and purpose limitation via Data Rights Registry
- **RBI (Banking pack):** AML/KYC agent modules; audit trails for approvals
- **IRDAI (Insurance pack):** Underwriting and claims workflows with governance layer
- **Data localization:** VPC / on-prem deploy option for sensitive workloads

## Payments

- Razorpay connector for INR billing (`RAZORPAY_KEY_ID`, `RAZORPAY_KEY_SECRET`)
- Stripe for international customers
